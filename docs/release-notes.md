## DeskMaster 1.0.0 — first release

Find out what fills your disk, clean it safely and move big folders to another drive.

**Download**
- **Windows:** `DeskMaster-win-Setup.exe` (installer that updates itself) or `DeskMaster-win-Portable.zip`
- **macOS (Apple silicon):** `DeskMaster-osx-Setup.pkg`
- **Linux:** the `.AppImage` file

**What's inside**
- Simple mode: one click frees space from safe caches and leftovers
- Pro mode: folder explorer with a treemap, largest files, duplicate finder, 48 cleanup rules
- Moves big app folders (Ollama, Hugging Face, NuGet, Gradle, pip, LM Studio) and Downloads to another drive, checking every file before the original is removed
- Low-space alerts and scheduled cleanup from the tray
- English and Arabic, light and dark
- `deskmaster-cli` for servers and scripts

The installers are not code-signed yet. On Windows choose **More info → Run anyway**; on macOS right-click the app and choose **Open**.
